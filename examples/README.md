# 📚 Pi TIA Agent Examples

This directory will contain practical examples, tutorials, and scripts to help you get the most out of the Pi TIA Agent integration.

## 🚀 Upcoming Examples

- **01-Basic-Discovery**: How to use the agent to map out an existing project.
- **02-Code-Generation**: Prompting the agent to create a complete SCL Function Block for a motor control.
- **03-Hardware-Automation**: Using the bridge to build a hardware configuration from a CSV list.
- **04-HMI-Sync**: Automatically generating HMI screens and tags from PLC data blocks.
- **05-Unit-Testing**: Creating and running automated consistency checks on your PLC code.
