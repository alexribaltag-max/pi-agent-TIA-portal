# Pi Agent TIA Portal Add-in

This folder contains a TIA Portal Openness Add-in designed to integrate the TIA Portal UI directly with the **Pi Coding Agent**.

When installed, it adds custom context menu options (e.g., right-click menus) to PLC blocks and Tag Tables. Clicking these options sends a lightweight JSON payload via HTTP (`localhost:31415`) to the running Pi Agent, which then uses the `TiaLocalBridge` to automatically fetch the relevant TIA object and perform the requested AI task (Review, Refactor, Explain, etc.).

## Next Steps: Installation

To use this Add-in in your local TIA Portal environment, follow these steps:

1. **Locate the compiled Add-in file:**
   Navigate to `TiaPiAddin/bin/Debug/net48/`. You only need ONE file:
   - `TiaPiAddin.addin`
   *(This is the packaged archive generated by the Siemens AddIn Publisher tool. Do not install the plain `TiaPiAddin/TiaPiAddin.addin` XML file from the project root.)*

2. **Copy to TIA Portal Add-ins folder:**
   Copy the `TiaPiAddin.addin` file into your TIA Portal installation's `AddIns` directory. For TIA Portal V20, this is typically:
   ```text
   C:\Program Files\Siemens\Automation\Portal V20\AddIns\
   ```
   *Note: If you previously copied `TiaPiAddin.dll` into this folder, delete it to prevent TIA Portal conflicts.*

3. **Activate the Add-in in TIA Portal:**
   - Open TIA Portal.
   - On the right side of the screen, open the **"Add-ins"** task card.
   - Expand the folder to find **Pi Agent Integration**.
   - Right-click the Add-in and select **Activate** (you may need to allow it privileges).

## Usage

1. Start your **Pi Coding Agent** session in your terminal. You should see the TIA Bridge tracking status at the bottom of the screen:
   `[TIA Bridge HTTP: :31415 | Portal: Connected | Project: YourProjectName]`
2. In TIA Portal's Project Tree, right-click any **PLC Block** (OB, FB, FC, DB) or **PLC Tag Table**.
3. At the bottom of the context menu, select an action like **"Pi Agent: Review Code"**, **"Pi Agent: Explain Block"**, or **"Pi Agent: Custom Prompt..."**.
4. If you choose **"Pi Agent: Custom Prompt..."**, a popup opens so the user can type a free-form instruction.
5. The Pi Agent will instantly acknowledge the request, fetch the block or hardware item via Openness/bridge, and start streaming its analysis!

## Development & Building

If you need to change the code (e.g., to support TIA V18 instead of V20):
1. Open `TiaPiAddin.csproj` and update the `<HintPath>` for `Siemens.Engineering.AddIn.dll`.
2. Rebuild using MSBuild from the developer command prompt or directly via standard command line:
   ```cmd
   "C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" "TiaPiAddin.csproj" -p:Configuration=Debug
   ```
3. Run the Siemens Publisher tool to package the DLL into an `.addin` file:
   ```cmd
   cd bin\Debug\net48
   "C:\Program Files\Siemens\Automation\Portal V20\PublicAPI\V20.AddIn\Siemens.Engineering.AddIn.Publisher.exe" -f AddInConfig.xml
   ```
   `AddInConfig.xml` is tracked in the project root and copied to `bin\Debug\net48` during build.
4. Overwrite the `.addin` file in your TIA Portal directory and restart TIA Portal.
